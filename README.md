# GlowFit – IPA über GitHub bauen
1. Auf github.com ein neues Repository anlegen (privat ist ok).
2. Alle Dateien dieses Ordners hochladen (auch den versteckten Ordner .github).
3. Reiter "Actions" > "Build IPA" > "Run workflow". Dauer ca. 10-15 Min.
4. Fertigen Lauf öffnen, unten bei "Artifacts" GlowFit-ipa laden und entpacken.
5. GlowFit.ipa in SideStore öffnen und installieren.
